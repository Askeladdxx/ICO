# ICO - A Fan Page

A fan-made website for the PlayStation 2 game ICO, with an overview,
characters, a gallery, and flip-through scans of the original manuals.

**Live site:** https://your-site-url-here

![Screenshot](./gallery/screenshot.png)

## Features

- Full-screen video landing page with background music
- Character cards and a filterable image gallery with a lightbox
- Flip-book viewer for the original PS2 manuals
- Responsive layout for phones, tablets, and desktops

## Built with

HTML, CSS, and vanilla JavaScript (no frameworks, no build step)

## Run locally

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**
   (or just double-click `index.html`).

## Project structure

- `index.html`, `style.css`, `script.js`: the landing page
- `manual.html`, `manual.css`, `manual.js`: the manuals viewer
- `Media/`, `gallery/`: images, video, and audio
